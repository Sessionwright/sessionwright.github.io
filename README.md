# sessionwright.github.io

The web side of [Sessionwright](https://github.com/Patri0s/Sessionwright):

- `open/` turns a link copied with *Copy link to this connection* (`https://sessionwright.github.io/open/#connect/host?id=…`) into the `sessionwright://` link the app opens. The part after `#` stays in the browser and never reaches the web server.
- `/` leads to the project.
